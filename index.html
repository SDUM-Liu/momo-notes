如何启动 SSH 服务？

手动直连 · 分享 SSH 地址

先在本设备开启 SSH 服务，再把登录信息分享给已配对的主设备。

在哪里找这些信息？

  1. 如果使用 Termux，先在其中运行 pkg install openssh 安装 OpenSSH。
  2. 运行 passwd 设置 SSH 登录密码，然后运行 sshd 启动服务。
  3. 运行 whoami 查看用户名，填到上方。Termux 默认端口为 8022，如已修改，请填实际值。

通常需连接同一局域网，或填写主设备能直接访问的地址。同步中继不转发 SSH 连接。

配置桃桃 AI

          
        

        
桃桃 AI 通过电脑上的 OpenAI Codex CLI 处理对话和便签问答，使用登录账号的 Codex 用量。

        
    
          
  1. 
            在电脑上安装或更新 Codex CLI
            
    按官方指南选择 Windows、macOS 或 Linux 的安装方式。电脑上已有 npm 时，也可以在终端运行 npm install -g @openai/codex。
    
            
            
          
    2. 
          
  2. 
            登录并打开桃桃 AI
            
    在电脑终端运行 codex login，用 ChatGPT 账号登录。然后重开桃桃便签，进入「设置 → 桃桃 AI」即可开始对话。
    
          
    3. 
          
  3. 
            在手机上继续使用
            
    先在「设备同步」配对手机。再到电脑的「设置 → 桃桃 AI」，在左侧「电脑端设置」开启「允许已配对设备使用桃桃 AI」。要让手机看到既有会话，可以开启下方的「向已配对设备共享当前账号的所有会话」，也可以在电脑上打开某条会话，点会话标题旁的「共享给已配对设备」。手机端打开历史会话后点「刷新」，使用时请保持电脑和桃桃便签在线。

第一次连接？
        

        
使用局域网地址时，让两台设备连同一个 Wi-Fi。异地连接需要电脑能访问的 SSH 地址。手机用流量时，可从设备列表选择「异地连接」。

        
第一次连接时，在终端核对目标设备的主机密钥指纹，再按终端提示登录。密码只在系统终端中输入。

      

      
桃桃 AI 主机名检查
        
允许后，桃桃 AI 可用这台电脑已验证的主机密钥和免交互登录方式读取设备主机名。
